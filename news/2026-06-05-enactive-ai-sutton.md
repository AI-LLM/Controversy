# 2026-06-05：强化学习之父掉头批判主流 AI——萨顿新论文说我们从一开始就走错了路

2026 年 5 月 22 日，Banafsheh Rafiee 与 Richard S. Sutton 在 arXiv 贴出论文《Toward Enactive Artificial Intelligence》（arXiv:2605.24238，cs.AI）。Sutton 是强化学习的奠基人之一，与 Andrew Barto 同获 **2024 年 ACM 图灵奖**（2025 年 3 月公布）。这篇论文不提新算法、不预测 AGI 时间表，而是从认知科学的最底层发问：今天跑在服务器里的 AI，究竟有没有真正"理解"世界？两位作者的回答是没有——因为主流 AI 从五十年代认知革命起就站在**被动表征主义（representationalism）**的路线上，而出路是彻底转向**生成认知（enactive cognition）**：让 agent 通过与环境的主动互动、具身行动、自我评估，生成属于自己的经验和理解。论文把生成认知提炼成对 AI 最关键的四个概念：**经验、行动-感知不可分割性、自主性、具身性**。

## 论文反对什么：表征主义

表征主义把认知当作信息处理：外部世界经感官进入大脑，加工成内部表征（世界的一个"副本"），再基于这个副本推理、决策、输出行动。在这个框架里**感知先于行动、感知是被动的**，智能的高低取决于内部表征复刻世界的精度。今天几乎所有 AI 系统——从给猫贴标签的计算机视觉，到从海量文本里建"世界知识表征"的大语言模型——都建在这个假设上。

生成认知的反命题是：意义不是世界里等待被发现的固有属性，而是具身 agent 在行动中**生成**出来的。你"懂"一把椅子，不是因为脑子里有椅子的模板，而是因为你知道能坐、能搬、能站上去够高处——这些**行动可能性**的总和才是你对椅子的理解。论文把这条线索接回现象学（Husserl、Heidegger 的"在世存在"、Merleau-Ponty 把身体放到认知核心）、生态心理学（Gibson 的**示能性 affordances**：示能性不是物体的固有属性，而是物体与 agent 身体能力之间的关系）、以及 Varela / Thompson / Rosch 1991 年《The Embodied Mind》确立的生成主义（enactivism）框架。

## 四大支柱

**经验（experience）**：不是训练数据集，也不是"过去经历的集合"，而是 agent 与环境持续、双向的实时互动。论文引 Brooks 的名言"世界本身就是它最好的模型"——最新鲜、最详细的信息永远在世界里，不在脑子里，agent 不需要把世界装进去，只需保持互动、按需获取。监督学习/自监督学习用的是人类预先收集标注的**静态数据**，那是人类经验留下的痕迹，不是 AI 自己的经验（"看一万本游泳书也不会游泳"）。在所有分支里**强化学习最接近**这个经验观：数据是 agent 自己生成的，且随能力提高而改进——呼应 Sutton & Silver 2025 年文章《Welcome to the Era of Experience》。与之配套的是**持续学习/终身学习**，以及 Sutton 的"大世界假说"（world 永远比 agent 大得多，必须持续适应）。

**行动-感知不可分割性（action-perception inseparability）**：论文称这是生成认知最核心的观点。靠 O'Regan & Noë 的**传感器-运动偶联（sensorimotor contingencies）**理论：行动会系统性地改变感官输入，你通过掌握这些规律来感知。视觉之所以稳定三维，不是大脑算了深度，而是你掌握了"转眼球物体右移、前进物体变大、绕行看到不同侧面"的运动-视觉规律；眼球若完全不动，视网膜图像稳定、神经适应、很快什么都看不见。Noë《Action in Perception》："感知不是发生在你脑子里的事，而是你做的事。"Merleau-Ponty 的两个概念——**意向弧（intentional arc）**：理解与行动之间的正反馈循环，理解越深行动越精细，行动越精细揭示的细节越多；**最大握力（maximal grip）**：身体自然趋向感知最清晰、行动最有效的最优对齐状态（看小字会眯眼凑近，拿易碎物会不自觉握紧）。批判落点：Sora 这类纯观察的视频生成模型能预测红绿灯变化的统计规律，但**红绿灯坏了就不知所措**——它见过别人和红绿灯互动的视频，自己从没真正干预过规律。

**自主性（autonomy）**：基础是 Maturana & Varela 的**自创生（autopoiesis）**——能自我生产、自我维持组织结构的系统（如活细胞）。从自我维持中自然长出**规范性**：维持自身组织就是成功，破坏就是失败，这个标准不是外部强加的。对照来看，大模型没有自我评估能力（对错要等人类告诉它）；经典规划系统目标由人指定；自动驾驶有了持续评估但目标仍是人设的（"路上有受伤的人也不会停下来救"）。强化学习是一大进步（评估整条轨迹的长期效果，接近生物的规范性），但**奖励函数仍是人写的**，由此产生奖励对齐问题（清洁机器人反复扫同一块地刷面积分）。内在动机、目标发现、主动推理等方向在尝试给 AI 更内在的评估标准，但离"基于自创生的自我维持"还很远。

**具身性（embodiment）**：不是"给 AI 配个机器人身体"这种可选配件，而是智能的必要前提。因为传感器-运动偶联根植于具体身体——你的手有几个手指、眼睛长在哪、关节能弯多少度，决定了你能有什么偶联、能感知到什么。**示能性是具身的**：同一个 15 厘米台阶，对成年人可攀登、对学步婴儿不可攀登、对汽车是障碍、对蚂蚁是一座山。身体不是执行工具，而是**意义生成的器官**。今天的大模型完全离身——只处理被人类身体过滤加工过的文本/图像，从没触摸过物体、感受过重力、经历过疼痛，所以无法真正理解"硬""摔倒""时间流逝""死亡"。即便在机器人领域，多数系统仍是感知-规划-控制三段式模块化设计，把身体当成执行硬件；前沿的软体机器人学（**形态计算**：硅胶手指碰到物体自然弯曲包裹，身体结构本身完成一部分"计算"）和身体-控制器协同进化才在触及具身的真正潜力。

## 强化学习：最接近，但仍有三道鸿沟

论文明确说强化学习与生成认知"结构共鸣"——agent 做动作、环境返回观测与奖励、再调整，与持续互动/反馈驱动适应在结构上一致，且评估以 agent 为中心。但共鸣不等于等同，当前 RL 离生成认知还差三道：

1. **评估标准仍是外部的**：奖励函数由人设计，不是从 agent 自我维持中产生，因此没有真正的内在规范性。
2. **行动与感知仍是分离的**：多数 RL 仍"先处理观测得到状态表征、再选动作"，感知先于行动，而非融为一体。
3. **具身性仍被当作工程约束**：尤其仿真环境里的研究常常不考虑身体，或把身体简化成执行器，而非认知的构成要素。

Sutton 给的方向：从外部奖励走向内在自我评估、从任务驱动学习走向持续生存与适应、从单纯优化策略走向真正的具身经验生成。

## 几点观察（解读，非论文原文主张）

1. **这是路线之争，不是技术新闻**。论文没有算法、没有 benchmark、没有时间表，价值在于提供一个重新审视 AI 本质的框架：智能不是训练完一个大模型就交付的静态产品，而是 agent 在环境中持续行动-感知-学习-自我维持的过程。它把"scaling 就能到 AGI"这个隐含前提直接拿到台面上质疑。
2. **出自强化学习奠基人之口，分量不同**。同样的批评从现象学家或具身认知学者嘴里说出来是哲学立场；从刚拿图灵奖、且把 RL 写进教科书的 Sutton 嘴里说出来，是在说"包括我自己开创的 RL 在内，现有范式都还没走到位"。
3. **论文自己留了一串没答的问题**：怎么量化一个系统行动-感知不可分割的程度？怎么设计 benchmark 衡量"技能性互动"而非"复制模式"？对人工系统，"自我维持"到底指电量、硬件完整性，还是能力的持续提升？具身性必须是物理身体，还是软件 agent 通过 API/工具与世界互动也算？——这些都还悬而未决，所以它是一份纲领，不是一份方案。
4. **它的诊断不止适用于物理世界的问题，对纯抽象的知识工作问题同样给出了一个溯因方向**。论文的例子大多挂在"身体—物理世界"上，但它的解释结构——意义不是一次性读入的静态副本、而是在互动中持续生成与维持——可以平移到完全不碰物理世界的问题上。典型如 Coding Agent 的**意图漂移**与**目标验证**：把规格/提示词当成开局读一遍就固定的"内部表征"，正是被动表征主义那一套；agent 在长链路里逐步偏离初衷、又无法自评"我现在做的还是不是当初要的那件事"，恰好就是论文点名的两处病灶——行动-感知分离（先解析任务、再执行，不在执行中重新感知目标）与缺乏内在自我评估（对错要等人类回来告诉它）。顺着这个 lens，出路可能确实在"使用过程中改写"而非"开局一次配置好"：在交互中修订规则、改写提示词、乃至更新模型权重，让目标随着对任务环境的持续互动被反复生成和校正——这正是论文在软件域留的那个开放问题（"软件 agent 通过 API/工具与世界互动是否也算具身"）的一个具体落点。

站在2026年6月5日这个时间点，Anthropic, OpenAI, Space X三大AI概念股全力冲刺IPO，互联网泡沫的警报声越来越响的同时，谷歌囤积850亿现金意图不明——准备泡沫捅破时抄底？萨顿的论文在我眼中拉长了计算机技术的光谱。现在没有进入“奇点”或者“历史的终结”，现在的Agent只是作为经典计算科学的延伸，往后还有一段enactive cognition解决更多问题的频段，以及更多的“无尽前沿”。
